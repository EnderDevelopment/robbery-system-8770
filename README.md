# Robbery System

A complete robbery system for FiveM servers with police alerts and rewards.

## Features

- Multiple robbery locations with different difficulty levels
- Police alerts when a robbery is in progress
- Cooldown system to prevent spamming
- Configurable robbery duration and rewards
- Database logging of robberies

## Requirements

- FiveM server
- ESX Framework
- MySQL

## Installation

1. Download the script
2. Place the files in your FiveM server's resources folder
3. Add `start robbery-system` to your server.cfg
4. Import the database.sql file into your MySQL database

## Usage

Players can rob locations by approaching them and pressing the interaction key. Police officers will be alerted if a robbery is in progress.

## Configuration

The script can be configured in the `config.lua` file. You can adjust robbery cooldowns, durations, rewards, and police settings.
